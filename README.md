# 🩺 Smart Health Data Visualization System

A web-based dashboard built using Streamlit that visualizes health-related data, predicts patient risks using machine learning models, and allows authenticated users to download reports and insights.

---

## 🚀 Features

- 📊 Interactive dashboard with real-time data visualizations
- 🔐 Secure user authentication
- 🤖 Machine Learning model to predict health outcomes
- 📁 Export reports to CSV
- 🧽 Automated data cleaning
- 💡 Built with Python, Streamlit, Pandas, Plotly, and scikit-learn

---
